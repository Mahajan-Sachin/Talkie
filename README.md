# 💬 Talkie

Talkie is a modern full-stack real-time chat application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).
It allows users to send instant messages and supports advanced features like video calling and audio messaging.

🌐 Live Demo: https://talkie-kiui.onrender.com/

---------------

## 🚀 Features

🔐 User Authentication (Login / Register)

💬 Real-time Messaging

📹 Video Calling

🎙️ Audio Messaging

📱 Responsive UI

⚡ Fast and Scalable Architecture

---------

## ⚙️ Installation & Setup (Local Development)
1️⃣ Clone the repository
```
  git clone https://github.com/sagarpandey19/Talkie.git
  cd Talkie
```
2️⃣ Setup Backend
```
cd backend
npm install
```

```
Create a .env file inside backend:

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

PORT=5000
```

Run backend:
```
npm start
```

3️⃣ Setup Frontend

Open new terminal:
```
cd frontend
npm install
npm start
```

🌍 Deployment

The application is deployed on Render:
```
🔗 https://talkie-kiui.onrender.com/
```
